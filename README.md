# Galactic Geckos: Space Kombat

Browser fighting game: Bolt versus The Colonel.

Production: https://ggspacekombatvercel.vercel.app/

## Development

Static site. Serve the repository root with a local HTTP server.
Run combat regression tests with `npm test` (Node.js 22 or later).

## Deployment

Use the existing Vercel project `gg_space_kombat_vercel` (project ID `prj_WYwd8keAWFoRRuaWZfL5tqAJzhe4`). Connect this repository, select main as the production branch, use the Other framework preset, and serve the repository root without a build command.

Import baseline: local source commit a491505. Gameplay assets and combat tests are preserved.
